## The Game

**Premise.** A top-down 2D action roguelike set in an elven forest. You pick a class, fight waves of enemies in a single forest arena, and get stronger during the run by leveling up. Clear all five waves to win. If you die, the run is over and you start fresh.

**What it's about.** Short, replayable runs built on challenging but fair combat. The game is built around three stats: HP, Speed and Strength. Each class starts with a different spread of them, and every level-up lets you raise one. Nothing carries over between runs, so how far you get comes down to your class, your choices and your skill.

### Classes

| Class | Best stat | Weak spot | Playstyle |
| --- | --- | --- | --- |
| Brawler | High HP | Low Speed | Wins by outlasting enemies |
| Assassin | High Speed | Low HP | Darts in and out |
| Mage | High Strength | Low HP | Hits hardest but dies fast |

### Aesthetic

A traditional fantasy RPG look with an elves-and-woods feel, in top-down 2D pixel art. The forest uses mossy greens, deep teal shadows and warm amber light. Enemies use colors that contrast with the forest so they're easy to read in a fight. Visual inspirations are classic Final Fantasy, and Hades for readable, punchy combat.
